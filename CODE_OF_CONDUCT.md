# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in the project, in
every space it uses: issues, pull requests, discussions, reviews and any other
channel where someone represents the project.

In short: be welcoming and respectful, assume good intent, give and take
feedback on the work and never on the person. Harassment, insults, personal or
political attacks, and publishing others' private information are not
tolerated.

## Reporting

To report behavior that breaks this code of conduct, use GitHub's
**Report content** action on the comment, issue or pull request concerned (the
`…` menu). Reports go to the project maintainers, privately. For a whole
account, use [Report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
on its profile.

Maintainers review every report, keep the reporter's identity private, and
decide on a response following the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban or permanent ban.
